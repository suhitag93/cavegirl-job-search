# profile/

Your source of truth. All three skills read from here.

| File | What it is |
|---|---|
| `resume-primary.md` | Your strongest lane, as plain markdown |
| `resume-secondary.md` | Your second lane |
| `target-companies.md` | The companies you actually want, with careers page URLs |

The real files are gitignored. Only the `.example.md` versions are committed,
so you can publish this repo without publishing your resume.

Keep resumes as plain markdown, one bullet per line, with the numbers in them.
The skills read these directly. If you edit the canonical copy somewhere else,
copy it back here, because these files are what get scored.
